1

नेटवर्क भनेको के हो?

Network भनेको दुई वा बढी device (laptop, phone, TV) आपसमा जोडिएर data आदानप्रदान गर्ने प्रणाली हो। घरको Router ले यी device लाई एकअर्कासँग र Internet सँग जोड्छ।

Home Network Builder
💻 Laptop↔ 📶 Router↔ 📱 Phone↔ 📺 Smart TV
📶 Router ↔ 🌐 ISP ↔ ☁️ Internet
🎯 के देख्नुभयो?

Internet line काटे पनि Laptop, Phone, TV बीचको local network भने चलिरहन्छ — किनभने casting/file-sharing को लागि बाहिरको Internet चाहिँदैन, घर भित्रको router मात्र भए पुग्छ।

कुनै पनि message पठाउँदा त्यो 7 तह हुँदै तल झर्छ (Encapsulation), अनि receiver मा उही 7 तह उल्टो क्रममा हुँदै माथि उक्लन्छ (Decapsulation)।

5

IP Address बनाम MAC Address

IP = घर बदल्दा बदलिने ठेगाना (Software ले दिने)। MAC = जन्म प्रमाणपत्रको number जस्तै, सधैं उही (device मा burn-in गरिएको)।

Laptop लिएर यात्रा गर्नुहोस्

MAC Address (Physical)

धेरै office/school ले MAC filtering प्रयोग गरेर "यी device मात्र जोडिन पाउने" भनी नियन्त्रण गर्छन् — किनभने MAC कहिल्यै बदलिँदैन।

Switch Operation (Layer 2)

Switch ले जोडिएका हरेक device को MAC address सिकेर आफ्नो MAC Address Table मा राख्छ। पहिलो पटक थाहा नभएसम्म सबैतिर पठाउँछ (flooding), पछि सीधै सही port मा मात्र पठाउँछ।

TCP बनाम UDP

TCP पहिले handshake गरेर connection बनाउँछ, हरेक data को ACK आउँछ — data हराउँदैन। UDP सीधै पठाउँछ, छिटो तर data हराउन सक्छ।
